ПРАКТИЧНА РОБОТА — ФІНАЛЬНЕ КОМПОНУВАННЯ WEB-САЙТУ

У папці є готовий навчальний приклад сайту:
- index.html — головна сторінка
- about.html — сторінка «Про сайт»
- gallery.html — галерея
- contacts.html — контакти
- css/style.css — стилі
- js/script.js — JavaScript
- images/ — зображення

ЯК ПЕРЕВІРИТИ:
1. Розпакуйте архів.
2. Відкрийте index.html у браузері.
3. Перевірте всі пункти меню.

ЯК ОПУБЛІКУВАТИ:
1. Створіть на GitHub новий Public-репозиторій.
2. Завантажте в нього вміст папки my-site (файл index.html має бути в корені).
3. У Settings → Pages виберіть Deploy from a branch, гілку main і папку /(root).
4. Збережіть налаштування та дочекайтеся публікації.

ВАЖЛИВО:
Це готовий демонстраційний приклад. Якщо у вас є власні сторінки з попередніх практичних робіт, замініть демонстраційний текст і зображення своїми файлами.
Для звіту потрібні посилання на сайт і репозиторій, а також скриншоти, зазначені в умові.
